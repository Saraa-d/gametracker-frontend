# GameTracker Frontend

Aplicación web para gestionar tu biblioteca personal de videojuegos con reseñas y estadísticas.

## 🎮 Características

- ✅ Gestión completa de biblioteca de juegos (CRUD)
- ✅ Sistema de reseñas con calificaciones
- ✅ Estadísticas visuales con gráficos
- ✅ Filtros y búsqueda avanzada
- ✅ Interfaz moderna y responsive
- ✅ Paleta de colores personalizada (rosado-vinotinto)

## 🚀 Tecnologías

- React 18
- Vite
- Axios (peticiones HTTP)
- Lucide React (iconos)
- CSS personalizado
