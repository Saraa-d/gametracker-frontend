# GameTracker Frontend

Aplicación web para gestionar tu biblioteca personal de videojuegos con reseñas y estadísticas.

## Características

- Gestión completa de biblioteca de juegos (CRUD)
- Sistema de reseñas con calificaciones por estrellas
- Estadísticas visuales con gráficos interactivos
- Filtros avanzados por estado
- Búsqueda en tiempo real
- Interfaz moderna y responsive
- Paleta de colores personalizada (rosado-vinotinto)
- Animaciones suaves y transiciones
- Optimizado para móviles y tablets

### Biblioteca
- Visualiza todos tus juegos en tarjetas elegantes
- Filtra por estado (Jugando, Completado, Pendiente, Abandonado)
- Busca por título, plataforma o género
- Agrega nuevos juegos con formulario modal
- Edita información de juegos existentes
- Elimina juegos con confirmación
- Estadísticas rápidas en el header

### Reseñas
- Escribe reseñas detalladas de tus juegos
- Sistema de calificación con estrellas (0-5)
- Selecciona el juego desde tu biblioteca
- Edita o elimina tus reseñas
- Busca reseñas por título o juego
- Estadísticas de reseñas escritas

### Estadísticas
- Visualiza tu progreso con gráficos de barras
- Top 5 juegos más jugados
- Top 5 juegos mejor calificados
- Top 5 plataformas más usadas
- Promedio de horas por juego
- Porcentaje de juegos completados
- Distribución por estado
- Total de horas invertidas

## Tecnologías
- React 18
- Vite (build tool)
- Axios (peticiones HTTP)
- Lucide React (iconos)
- CSS personalizado con variables CSS
- GitHub Pages (hosting)
